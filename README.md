# 🎵 Craftopia Music - Discord Music Bot & Spotify-Style Dashboard

Craftopia Music là một Discord Music Bot cao cấp đi kèm Web Dashboard điều khiển trực tiếp thời gian thực mang phong cách thiết kế của Spotify Web Player.

## ✨ Tính năng nổi bật
- **Giao diện Spotify Desktop**: Bố cục hiện đại, thanh phát nhạc cố định dưới đáy, hiệu ứng đĩa than cơ học xoay theo nhịp nhạc.
- **Audio Visualizer**: Cột sóng âm quang phổ chuyển động mượt mà.
- **Thanh Seekbar thông minh**: Kéo tua trực tiếp từng giây, hiển thị bong bóng thời gian nổi (Tooltip).
- **Chế độ Toàn màn hình (Theater Mode)**: Trình chiếu đắm chìm với ảnh bìa cỡ lớn và hiệu ứng mờ nhòe backdrop.
- **Âm thanh chất lượng cao**: Sử dụng công nghệ trích xuất luồng tối ưu, không giật lag.
- **Tích hợp Cloud 24/7**: Sẵn sàng chạy trên Render.com hoàn toàn miễn phí.

## 🚀 Khởi chạy cục bộ
```bash
npm install
npm start
```
Mở trình duyệt: `http://localhost:3000`

## ⚙️ Cấu hình môi trường (.env)
```env
DISCORD_TOKEN=your_bot_token
CLIENT_ID=your_client_id
CLIENT_SECRET=your_client_secret
PORT=3000
```
